How to check these numbers

  • This page reads marks.csv, trades.csv and positions.json from this repository. The commit history shows when each row arrived.
  • Trades are never back-dated: a buy or sell uses the next open after the rule fires, and rules.md was fixed before the first trade on 18 Oct 2026.
  • Every weekday evening a GitHub Action rebuilds the portfolio value from the trade list with its own Yahoo Finance download and writes the result to verify/. See verify.py.
  • Virtual money only. Nothing here is a real order.
